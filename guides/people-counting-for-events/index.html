Guide

People counting for events and temporary sites

Pop-ups, festivals and expos need counting that goes in fast, runs anywhere and comes out afterwards. Here is how it works.

Events and temporary sites need people counting that can be installed quickly, run without fixed infrastructure, and be removed when the event ends, all while producing numbers you can report with confidence.

Fast, temporary installs

Counters for temporary sites install quickly and can be set up for a single event, a short lease or a works period, with live dashboards from the first day.

No fixed power or network

Battery, solar and mobile-data sensors need no power or cabling at the counting point, so they work at outdoor festivals, pop-ups and sites with no fixed infrastructure.

Crowd safety and capacity

For dense temporary crowds, live occupancy and crowd density, with alert thresholds, let control teams act before conditions become unsafe.

Reporting to sponsors and funders

Objective attendance, by entrance and hour, with staff and re-entries handled, turns a busy day into a defensible number for sponsors, exhibitors and funders.

Removed afterwards

When the event ends, temporary sensors come out. You keep the data and the report without a permanent install.

FAQ

Questions & answers

How quickly can counting be set up for an event?

Counters for temporary sites install quickly and run on battery and mobile data, so an event can be measured from the first day with no cabling.

Can it be installed just for the event?

Yes. Temporary deployments are set up for the event and removed afterwards, with live dashboards throughout. You keep the data and the report.

Can it keep crowds safe?

Yes. Live occupancy and crowd density, with alert thresholds, let control teams manage dense crowds before conditions become unsafe.
